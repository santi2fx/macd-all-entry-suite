MACD All Entry (Suite) — Quick Card

Beginner cheat sheet · v1.12+ · MQL5\Indicators\Entry Suite\MACD All Entry (Suite).ex5 · Indicator only — it never trades.

1 · Install (once)

  1. MT5 → File → Open Data Folder
  2. Open MQL5\Indicators\Entry Suite\
  3. Copy MACD All Entry (Suite).ex5 (compile .mq5 with F7 if needed)
  4. MT5 → right-click Navigator → Refresh
  5. Drag the indicator onto a chart

2 · Sensible first settings

InputValue
InpActiveModes"11" or ALL
InpExpList"1,2,3,4,5" → E1..E5
InpStatsBars1000–3000
InpMinTrades10
InpPipModeFX = PIP_AUTO, gold/index = PIP_TEN_POINTS
InpShowTopPips / InpShowTopAvgtrue / true

3 · What is on the chart

  • Green ↑ = BUY, red ↓ = SELL (one arrow max per bar, no repaint)
  • Text like mode 11 = the rule that produced the last arrow
  • Model: signal on a closed bar → entry at next bar open → exit at close of bar + E

7 · Research workflow

  1. Pick symbol + timeframe
  2. Set pip mode, verify the pip line
  3. Set InpActiveModes (ALL while exploring)
  4. Open TOP PIPS or TOP PIPS/TRADE
  5. Pick mode + E where n, Win%, p/t, LS look sane
  6. Save CSV (InpExportCSV) as evidence
  7. Switch panels off, keep only the chosen mode
  8. Hand the chart / buffers to your EA

9 · Common problems

  • No arrows → InpShowArrows off, or history too short
  • “no combo reaches N trades” → lower InpMinTrades, raise InpStatsBars
  • Wrong pip values → wrong InpPipMode
  • Panels overlap → change InpTopAvgY or the corner
  • Inputs ignored → press OK in the properties dialog
Risk notice. Statistics are in-sample on loaded history. No SL/TP is modelled. High win% with negative p/t is possible and PF = inf does not mean low risk. Past results never guarantee future results. Not investment advice.
Before going live: re-test the chosen mode + expiration on another period (walk-forward) or in Strategy Tester, and let your EA handle SL, TP and position size.
