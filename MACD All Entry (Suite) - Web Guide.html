MACD All Entry (Suite) — User Guide

A beginner-friendly guide to the Entry Suite MACD indicator: what it draws, how to read the statistics panels, how to set “pips” correctly on FX, metals and indices, and how to hand a verified rule to your own Expert Advisor.

It never trades. The indicator only draws BUY/SELL arrows and prints statistics from history. It does not open, close or manage orders, and it is not investment advice. All numbers are in-sample on the history loaded in your terminal.

1 · What it does

price → MACD (EMA 12 / EMA 26) → signal (EMA 9)
                                  │
                    20 rules (mode 1..20)
                                  │
       ┌──────────────────────────┼───────────────────────────┐
       │                          │                           │
 chart arrows             statistics panels              CSV export
 buy / sell               win%, pips, TOP/WORST         for later review
Mode
One of 20 entry rules: MACD/Signal cross, zero cross, histogram turn, slope, divergence, …
Expiration (E)
Bars held after the signal. E3: enter at the next bar’s open, exit at the close of signal bar + 3.
No repaint
Everything is computed on closed bars, so a finished arrow is never moved or removed.

2 · Install

  1. MT5 → File → Open Data Folder.
  2. Open MQL5\Indicators\Entry Suite\.
  3. Copy MACD All Entry (Suite).ex5 into it (compile the .mq5 with F7 if you only have source).
  4. Back in MT5: right-click Navigator → Refresh.
  5. Drag MACD All Entry (Suite) onto a chart.

4 · The two ranking tables

Each table is an independent panel with its own on/off switch, corner and offset.

TOP TOTAL PIPS — InpShowTopPips
Sorted by total net pips. High-frequency rules naturally rank high; that is not “better per trade”.
TOP PIPS / TRADE — InpShowTopAvg
Sorted by average pips per trade — a quality view for risk-conscious traders.
TOP TOTAL PIPS  n>=10  sorted by net pips
  # Md Mode                Exp  Win%    pips    n    p/t    PF LS
1 11 Cross Zero Strong     E3   62.5  +180.4   48   3.76  2.90  3
ColumnMeaning
#rank inside this table
Mdmode 1..20; > = ACTIVE (combined)
Modemode name
Expbars held
Win%wins ÷ (wins + losses)
pipsnet pips of the combo
ntrades used
p/tpips per trade (expectancy)
PFgross win ÷ gross loss; inf = no losing trade yet
LSlongest losing streak

InpShowWorstPips / InpShowWorstAvg append a WORST block to each table; InpTopN sets rows per block (1..5). Combos below InpMinTrades are never ranked.

5 · Pips — set this correctly

AssetExample1 pipSetting
EURUSD, GBPUSD (5 digits)1.085420.0001PIP_AUTO
USDJPY, GBPJPY (3 digits)149.5230.01PIP_AUTO
XAUUSD (2 digits)2650.150.1 = 10 pointsPIP_TEN_POINTS
US500 / NAS1005200.50.1 or 1.0PIP_TEN_POINTS or PIP_CUSTOM
BTCUSD / ETHUSD~1000001.0 or 0.1PIP_CUSTOM
  • PIP_AUTO — 3/5 digits → 10 points, otherwise 1 point (old behaviour)
  • PIP_POINTS — 1 pip = 1 point
  • PIP_TEN_POINTS — 1 pip = 10 points
  • PIP_CUSTOM — 1 pip = InpPipCustomPoints points
Verify: line 2 of the main panel shows Pip 0.10 = 10.0 pts. If it does not match your broker, change InpPipMode and look again.
Never compare pips across symbols: 0.1 on XAUUSD is not 0.0001 on EURUSD. Compare inside one symbol, or across timeframes of that symbol.

6 · Research workflow

  1. Pick a symbol and timeframe you understand.
  2. Set the pip definition and verify the Pip … = … pts line.
  3. Set InpActiveModes (use ALL while exploring).
  4. Open the table you need: TOP total pips or TOP pips/trade.
  5. Choose a mode + expiration where n is high, Win% and p/t agree, and LS is acceptable.
  6. Record it, or enable InpExportCSV once to keep the table.
  7. Switch the panels off and leave only the chosen mode active.
  8. Hand the chart or the indicator buffers to your EA.

Switching panels off never changes signals or buffers — it only removes chart objects.

7 · CSV export

  • Enable InpExportCSV; the file is rewritten on each stats recalculation.
  • Location: MQL5\Files\EntrySuite_MACD_<SYMBOL>_<TF>.csv.
  • Header rows: symbol, timeframe, server_time, stats_bars, active_modes, min_trades, pip_mode, pip_points.
  • Then ACTIVE,combined and one row per mode with E{k}_win%, E{k}_n, E{k}_pips.

10 · Using it from an Expert Advisor

BufferValue
0 / 1Buy / Sell arrow (price or EMPTY_VALUE)
2..21mode 1..20: 1.0 buy, -1.0 sell, 0.0 none
22 / 23Buy / Sell combined (enabled modes)
24 / 25 / 26MACD / Signal / Histogram
 
// pass only leading inputs, the rest use indicator defaults
int h = iCustom(_Symbol, _Period, "Entry Suite\\MACD All Entry (Suite)",
                12, 26, 9, PRICE_CLOSE, "1,2,3,4,5", "11");
if(h == INVALID_HANDLE) return;

double buy[];
if(CopyBuffer(h, 22, 0, 3, buy) > 0 && buy[0] > 0.5)
{
   // combined BUY signal (buffer 23 = SELL)
}

Inputs are positional. To set a later input, pass every earlier one: Fast, Slow, Signal, AppliedPrice, ExpList, ActiveModes, PipMode, PipCustomPoints, FractalBars, DivLookback, DivFirstBreak, StatsBars, MinTrades, StatsOnSignalOnly, LogStats, ShowArrows, ShowModeTag, ColorTag, ExportCSV, ArrowOffsetPts, ShowPanel, PanelView, SortByWinRate, PanelCorner, PanelX, PanelY, FontSize, PanelBack, ColorTitle, ColorText, ColorActive, ColorBest, ColorBg, ShowTopPips, ShowTopAvg, ShowWorstPips, ShowWorstAvg, TopN, TopPipsCorner, TopPipsX, TopPipsY, TopAvgCorner, TopAvgX, TopAvgY, AlertPopup, AlertSound, SoundFile, AlertPush, AlertEmail. Call IndicatorRelease(h) in the EA’s OnDeinit.

12 · Limits and risk

  • All statistics are in-sample on the loaded history — not a forward test.
  • Picking the best of 20 modes × many expirations on one dataset is curve fitting; validate elsewhere.
  • No SL/TP is modelled: “pips” means hold N bars and exit at the close.
  • High win% with negative p/t is possible — read them together.
  • PF = inf means “no losing trade in this window”, not low risk.
  • Past results do not guarantee future results. Not investment advice.

13 · Pre-live checklist

  • Pip mode matches the asset and the panel pip line looks right
  • InpStatsBars 1000–3000 and InpMinTrades ≥ 10
  • Chosen combo has enough trades, agreeing win% / pips per trade, acceptable losing streak
  • Re-tested on another period or neighbouring timeframe
  • CSV saved as evidence
  • Unused panels switched off before handing the chart to an EA
  • SL, TP and position size handled by your EA
